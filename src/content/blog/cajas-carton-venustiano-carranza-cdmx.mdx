## Cómo calcular cuántas cajas necesitas

Para florerías de Jamaica con alta rotación, el cálculo diario es clave:

```
Cajas diarias = Arreglos o bouquets producidos / Piezas por caja
Pedido semanal = Cajas diarias x 6 días + 25% de margen
```

**Ejemplo real — Mayorista de flores en Jamaica:**

- Producción diaria: 300 bouquets, 3 por caja
- Cajas diarias: 300 / 3 = 100 cajas
- Pedido semanal base: 100 x 6 = 600 cajas
- Margen 25%: 600 x 1.25 = **750 cajas/semana**

Con pedidos semanales de 750 cajas de corrugado encerado para flores, el precio cae de $22 (proveedor local) a $16. Ahorro semanal: **$4,500 MXN**; ahorro anual: **$234,000 MXN**.
